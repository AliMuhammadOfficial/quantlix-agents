# Quantlix public agent resources

Official public content skills and a read-only MCP configuration for [Quantlix](https://quantlix.com/).

Read the [developer guide](https://quantlix.com/en/developers/), [OpenAPI](https://quantlix.com/openapi.json), [authentication guide](https://quantlix.com/auth.md), and [when-to-use instructions](https://quantlix.com/llms.txt).

Install skills with `npx skills add AliMuhammadOfficial/quantlix-agents`. Agent Plugins clients can load this directory's plugin.json and mcp.json. No credential is needed for public reads. These resources do not offer model execution, payments or administrative actions.

Use quantlix-service-research to find and cite relevant public evidence. Use quantlix-inquiry-preparation to draft an inquiry for the person's review; it does not authorize sending or automatically retrying a submission.

Official verified listing: [com.quantlix/content](https://registry.modelcontextprotocol.io/v0.1/servers/com.quantlix%2Fcontent/versions/latest).
